## 写在前面

今天给大家带来博客的全新功能 —— **实用工具页面**！这个页面整合了我平时经常用到的一些在线工具，方便自己使用，也希望能帮到大家。

## 功能概览

目前工具页面包含以下工具：

### 🕐 时间戳转换器

- 支持毫秒级（13位）和秒级（10位）时间戳互转
- 实时显示当前时间戳
- 一键跳转到常用时间点（Unix纪元、千禧年、2021年、2025年）
- 显示相对时间（xx分钟前、xx天后等）

### 📱 二维码生成器

- 支持多种内容类型：文本、URL、WiFi、名片
- 可调节二维码大小和容错率
- 自定义前景色
- 支持下载 PNG 和 SVG 格式

### 🌐 浏览器信息检测

- 全面检测浏览器版本、内核、操作系统
- 硬件信息（CPU核心数、内存、电池等）
- 隐私指纹检测（Canvas、WebGL、字体等）
- 网络状态和屏幕信息

### 🔑 小米相关工具

- **AuthKey 提取器**：从安卓日志或 iOS 数据库提取设备连接所需的 AuthKey
- **设备解锁码计算**：计算小米穿戴设备的解锁码

### 🎬 网页播放器

- 支持本地文件和 URL 播放
- 支持多种视频格式（MKV、MP4、WebM、MOV、AVI、TS、M2TS）

## 隐私保护

所有工具都在**本地浏览器中运行**，不会上传任何数据到服务器：

- 二维码生成：完全本地处理
- 浏览器检测：使用 JavaScript 获取本地信息
- 文件上传（如 AuthKey 提取器）：使用 FileReader API 在浏览器端处理，不经过服务器

## 技术实现

工具页面基于 Astro 框架开发，使用了以下技术：

- **Astro 静态站点生成**：快速加载，SEO 友好
- **Tailwind CSS**：响应式设计，适配各种设备
- **TypeScript**：类型安全
- **qrcode 库**：二维码生成
